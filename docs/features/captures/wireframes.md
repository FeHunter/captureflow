# Wireframes e estrutura de tela — Captures

## Navegação global
```text
CaptureFlow v{versionName}
┌────────────────────────────────┐
│ Referências                     │
│ [Selecionar imagem]              │
│ [Salvar texto ou link]           │
│ [Buscar referências]             │
│ [Filtros de categoria]           │
│ ┌────────────────────────────┐  │
│ │ Capa da imagem (opcional)   │  │
│ │ Título + categoria          │  │
│ │ Texto/descrição             │  │
│ │ [Analisar imagem]            │  │
│ └────────────────────────────┘  │
├────────────────────────────────┤
│ Referências             Checklist│
└────────────────────────────────┘
```

## Cartão de referência
A imagem, quando existente, fica no topo como capa. O título e a categoria aparecem abaixo, seguidos do conteúdo/descrição e das ações aplicáveis.

## Cartão de tarefa
Título, conclusão, exclusão, capa opcional, descrição e ação para analisar screenshot.

Wireframe textual; não substitui validação visual em dispositivo.
