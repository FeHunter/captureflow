# Image Import

Entradas: Sharesheet texto/URL/imagem, Photo Picker, câmera CameraX e monitoramento opt-in de screenshot. Link fica pendente até revisão/confirmação de categoria; cancelar não persiste. YouTube tenta oEmbed oficial para título/thumbnail; outros sites usam H1/metadados e imagem article/main/body. Download de capa após confirmação.

OCR ML Kit on-device sugere título editável; erro não descarta imagem. Câmera tem foco por toque e recorte; Photo Picker/compartilhamento têm revisão própria. Copiar para storage privado quando possível; URI original fallback. Nunca apagar imagem escolhida manualmente. Screenshot discovery best-effort por MediaStore via serviço em primeiro plano `specialUse`, iniciado somente após ativação explícita do usuário e concessão de READ_MEDIA_IMAGES e POST_NOTIFICATIONS (Android 13+). No Android 14+, também declara READ_MEDIA_VISUAL_USER_SELECTED para identificar acesso limitado; o serviço só inicia com READ_MEDIA_IMAGES concedida, pois acesso parcial não permite detectar todas as novas screenshots. O serviço permanece ativo até o usuário desativá-lo pela notificação persistente ou pelo cabeçalho do app; não há inicialização automática após reboot. `START_STICKY` permite ao Android tentar recriar o serviço após encerramento do processo, respeitando a preferência ativa e as permissões. A consulta lê somente metadados, usa watermark incremental por DATE_ADDED e deduplicação de URIs; não lê pixels durante a varredura, não captura tela e não usa Accessibility/overlay. Cada screenshot detectada gera uma notificação que abre a prévia in-app; só importa após confirmação explícita e escolha de categoria. A imagem original permanece na galeria. Antes de solicitar permissões, a UI apresenta uma explicação destacada do monitoramento contínuo, do acesso completo exigido, da notificação persistente e da confirmação exigida para importar. Cancelar a explicação não solicita permissões e não bloqueia o Photo Picker. Photo Picker permanece como alternativa manual quando as permissões não são concedidas. Parser não executa JS.

## Armazenamento de previews
Downloads de thumbnails passam pelo ImageCompressionService antes de serem retornados como URIs privadas. Se download, decodificação ou compressão falhar, não persistir o arquivo temporário original; manter o link como fallback. Imagens selecionadas usam cópia/compressão privada quando possível.
