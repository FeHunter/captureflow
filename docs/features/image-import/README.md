# Image Import

Entradas: Sharesheet texto/URL/imagem, Photo Picker, câmera CameraX e monitoramento opt-in de screenshot. Link fica pendente até revisão/confirmação de categoria; cancelar não persiste. YouTube tenta oEmbed oficial para título/thumbnail; outros sites usam H1/metadados e imagem article/main/body. Download de capa após confirmação.

OCR ML Kit on-device sugere título editável; erro não descarta imagem. Câmera tem foco por toque e recorte; Photo Picker/compartilhamento têm revisão própria. Copiar para storage privado quando possível; URI original fallback. Nunca apagar imagem escolhida manualmente. Screenshot discovery best-effort por MediaStore somente enquanto MainActivity está em primeiro plano (resumed); observer é registrado em onResume e fechado em onPause. Não há foreground service, notificação persistente ou detecção em segundo plano. A detecção consulta apenas metadados recentes e não lê pixels durante a varredura nem usa Accessibility/overlay. Ao detectar screenshot, exibe prévia in-app; só importa após confirmação explícita. Antes de solicitar READ_MEDIA_IMAGES, a UI apresenta uma explicação destacada do uso de metadados, da limitação ao primeiro plano e da confirmação exigida para importar. Cancelar a explicação não solicita permissão e não bloqueia o Photo Picker. Photo Picker permanece como alternativa manual quando a permissão ampla não é concedida. Parser não executa JS.

## Armazenamento de previews
Downloads de thumbnails passam pelo ImageCompressionService antes de serem retornados como URIs privadas. Se download, decodificação ou compressão falhar, não persistir o arquivo temporário original; manter o link como fallback. Imagens selecionadas usam cópia/compressão privada quando possível.
